# mstack review

Read the applicable repository instructions and preserve the working tree.
Follow [the review procedure](../mstack/references/review.md).
When independent reviewers would help and delegation is authorized, read the
[Codex adapter](../mstack/references/codex.md), or the
[T3 adapter](../mstack/references/t3.md) when T3 tools are available.
Do not modify the reviewed change or publish review comments unless requested.
