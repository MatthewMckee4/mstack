# Native Codex adapter

Use the tools exposed in the active session. Native agent names and capacity vary by
Codex surface; a file in this package does not register a custom agent type.

When delegation is useful and authorized, prefer native agents for supported same-model
work without model-option requirements. Do not claim model diversity unless the host
actually exposes and serves distinct models. For T3 routing, use [T3 Code](t3.md).

Give a child the objective, repository and checkout, exact scope, relevant instructions,
inputs, acceptance checks, and expected evidence. Read-only reviewers can share a
checkout only when their commands do not mutate it. Writable tasks require separate
worktrees or explicit exclusive file ownership. Tests and builds can write artifacts;
account for those too.

A child starts from the available snapshot, not the parent's unsaved assumptions.
Confirm the head and whether uncommitted edits are included. Do not let multiple writers
edit the same files concurrently. Integrate deliberately and run the final checks in
the parent's actual tree.

If native delegation is unavailable, do the work serially. Report the loss of independent
or multi-model review when it matters. If the user explicitly requires a capability
that is unavailable, explain the blocker rather than simulating it.

Use the repository's Git and browser workflows. Respect the user's browser preference
and preserve its relevant profile and session. Do not invent Cursor commands, model
catalogs, persistent mode activation, or task-history access.
